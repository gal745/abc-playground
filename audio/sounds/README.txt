OPTIONAL: your own letter sounds
================================

The games use the computer's voice to say letter sounds, which is only approximate.
To use your own voice instead, record each sound and save it here as:

  a.mp3  b.mp3  c.mp3  ...  z.mp3

Say just the pure sound (e.g. "mmm", "sss", a short "b" without a big "uh").
You don't need all 26: any letter without a file keeps using the computer voice.
